# Machine Learning Pipeline

This document focuses on the machine learning component of NewsChecker, including the dataset, model selection, training process, evaluation, and current limitations. The preprocessing pipeline and overall application architecture are documented in the README.

## Dataset

NewsChecker was trained using a publicly available Kaggle dataset containing URLs to news articles labeled for fake news detection. Each article is assigned a binary label, where 0 represents fake news and 1 represents real news. The dataset can be found [here.](https://www.kaggle.com/datasets/algord/fake-news)

Although the original dataset contained 21,724 unique articles, only 11,039 articles were successfully processed by the data collection pipeline. The remaining articles were excluded due to issues encountered during article retrieval and extraction, such as failed HTTP requests or cases where the pipeline was unable to extract usable article text. Only the processed articles were used for training because the excluded articles did not produce the text required for embedding generation and model training.

The 11,039 successfully processed articles were split into three separate datasets:

- **Training set: 7,727 articles (70%)**
- **Validation set: 1,655 articles (15%)**
- **Testing set: 1,657 articles (15%)**

The training set was used to train the model, the validation set was used to evaluate the model during development, and the test set was used to evaluate how well the model performs on data it had never seen during training.

### Class Distribution

The processed dataset contains 2,495 fake news articles and 8,544 real news articles. As a result, the dataset is imbalanced, with substantially more real news articles than fake news articles. The table below shows the number of fake and real news articles in each dataset:

| Dataset    | Fake Articles (0) | Real Articles (1) | Total  |
| :-----:    | :---------------: | :---------------: | :---:  |
| Training   | 1,737             | 5,990             | 7,727  |
| Validation | 375               | 1,280             | 1,655  |
| Testing    | 383               | 1,274             | 1,657  |
| Total      | 2,495             | 8,544             | 11,039 |

Because the dataset contains significantly more real news articles than fake news articles, the classes are imbalanced. As a result, overall accuracy does not provide a complete picture of the model's performance, so additional evaluation metrics were used.

## Model

### Model Selection

NewsChecker uses a Logistic Regression model to classify news articles as either trustworthy or untrustworthy.

#### Why Logistic Regression?

Logistic Regression was chosen because it is a strong baseline model for binary classification problems like determining whether a news article is trustworthy or untrustworthy. It is simple to train, makes predictions quickly, and works well with dense sentence embeddings such as those generated by the `all-mpnet-base-v2` SentenceTransformer model.

Another advantage of Logistic Regression is that it produces a probability score for every prediction instead of only a binary label. This allowed NewsChecker to present users with confidence levels (such as "Probably Trustworthy" or "Likely Untrustworthy") rather than only classifying articles as trustworthy or untrustworthy.

### Model Input

Instead of using the raw article text as input, the model uses **sentence embeddings** generated by the **all-mpnet-base-v2** SentenceTransformer model.

During preprocessing, each article is split into multiple chunks, and an embedding is created for each chunk. These embeddings are then averaged using `np.mean(embeddings, axis=0)` to create a single embedding that represents the entire article. The resulting 768-dimensional embedding captures the semantic meaning of the article as a whole. This embedding is then used as the input to the Logistic Regression model.

### Training

The model was trained using **scikit-learn's** `LogisticRegression` class.

The following hyperparameters were used during training:
- `max_iter=1000` to give the model enough opportunities to learn from the training data before stopping.
- `class_weight='balanced'` to account for the dataset's imbalance between fake and real news articles (approximately 23% fake and 77% real), helping the model learn from both classes more fairly.

### Predictions

For each article, the model produces:
- A binary prediction indicating whether the article is trustworthy or untrustworthy.
- A confidence score, generated using `predict_proba()`, that estimates how confident the model is that an article is trustworthy.

The confidence score is displayed using the following trustworthiness labels:
- 0.0 – 0.2: Likely Untrustworthy
- 0.2 – 0.4: Probably Untrustworthy
- 0.4 – 0.6: Uncertain
- 0.6 – 0.8: Probably Trustworthy
- 0.8 – 1.0: Likely Trustworthy

### Saving the Model

After training, the model is saved using **joblib.** This allows the trained model to be loaded later for predictions without needing to train it again.

### Performance

Making a prediction for a news article usually takes a few seconds. Most of this time is spent generating sentence embeddings using the `all-mpnet-base-v2` model. Once the embedding has been created, the Logistic Regression model makes its prediction almost instantly.
